# RP Revisited website

The public site for the RP Revisited Garry's Mod server, served by GitHub Pages from `main`.

- `index.html` the page, `style.css` the look (same colours as the in-game UI), `site.js` settings.
- To show a Join button, set `serverAddress` in `site.js`. For a Discord link, set `discord`.
- No secrets here: this repository is public. Database details stay on the game server.
